- AI가 물어서 내가 정한 것:
1. 누가 사용하는가 -> 친구들도 같이 보고 만들 수 있음
2. 어떻게 보여줄 것인가 -> 링크로 공유함
3. 어떤 기기에서 사용할 것인가 -> PC가 메인
4. 얻고 싶은 결과 -> 내 취향을 한눈에 보여주고, 친구들의 취향과 비교하면서 이야기할 거리를 만드는 것
5. 링크를 열었을 때 할 수 있는 일 -> 내 티어리스트를 본 뒤, 같은 영화로 자기 티어리스트를 한 화면에서 만들어 볼 수 있음
6. 등급은 몇 개, 어떤 이름으로 할 것인가 -> A/B/C/D/F
7. PC에서 영화를 등급으로 옮기는 방식 -> 끌어다 놓기와, 영화를 클릭한 뒤 등급 칸을 클릭해서 옮기기
8. 같은 등급 안에서 순서에 의미가 있는가 -> 없음
9. 친구들의 결과는 어떻게 모을 것인가 -> 자동으로 모으기. 같은 페이지에서 친구가 이름을 적고 저장하면 비교 화면에 바로 나옴
10. 페이지를 닫았다가 다시 열었을 때 작업이 남아 있어야 하는가 -> 남아 있어야 함
11. 영화는 어떤 모습으로 보여 줄 것인가 -> 제목과 개봉 연도가 적힌 색깔 카드, 이미지는 각자 직접 올리기
12. 영화 목록은 8편으로 고정하는가 -> 8편으로 시작하고, 각자 영화를 추가하거나 뺄 수 있음
13. 비교 화면은 어떤 형태인가 -> 영화마다 각자 준 등급을 한 줄에 표시 (영화 이름 - 닉네임별 등급)
14. 친구가 올린 이미지가 비교 화면에서 다른 사람에게도 보여야 하는가 -> 모두에게 보여야 함
15. 저장한 결과를 나중에 고치거나 지울 수 있어야 하는가 -> 비밀번호 없이 고칠 수 있게 함
16. 디자인 분위기 -> 어두운 영화관. 검정 배경에 은은한 조명색, 극장에 들어온 느낌

행동으로 비교한 결과(해본 행동 → 기대 결과 → A의 결과 / B의 결과):
- 영화를 클릭해서 A칸으로 옮기기 → A칸으로 옮겨짐 → A 됨 / B 됨
- 영화를 끌어다 B칸에 놓기 → B칸으로 옮겨짐 → A 됨 / B 됨
- 영화 추가하기 → 대기 칸에 새 카드가 생김 → A 됨 / B 됨
- 영화 빼기 → 카드가 없어짐 → A 됨 / B 됨
- 영화를 A칸으로 옮기고 닫았다가 다시 열기 → A칸에 그대로 남아 있음 → A 됨 / B 초안은 안 됨 (처음 배치로 돌아감, 수정본에서 고침)
- 카드에 이미지 올리기 → 카드에 이미지가 보임 → A 됨 / B 됨
- 2명 이름으로 저장하고 비교 화면 보기 → 영화별 표에 2명이 나오고 올린 이미지도 보임 → A 됨 / B 초안은 이미지가 안 보임 (수정본에서 고침)
- 같은 이름으로 등급을 바꿔서 다시 저장하기 → 비밀번호 없이 새 결과로 바뀜 → A 됨 / B 됨
- 친구가 링크로 들어와 저장하면 같이 모이는지 확인 → 비교표에 자동으로 모임 → A 안 됨 / B 안 됨 (둘 다 결과 파일을 내보내고 불러오는 방식으로 대신함)
- 결과 파일을 내보낸 뒤 기록이 없는 브라우저에서 불러오기 → 비교표에 그 사람 결과가 나옴 → A 됨 / B 됨
- PC 화면(가로 1280, 1920)에서 보기 → 깨지지 않음 → A 됨 / B 됨
