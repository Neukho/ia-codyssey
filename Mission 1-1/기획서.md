# 영화 티어리스트 웹페이지 기획서

작성일: 2026-11-03
참고 자료: 아이디어.md

---

## 1. 누가 쓰나

- 나와 영화를 좋아하는 친구들
- 내가 링크를 보내면 친구가 자기 기기에서 열어 사용
- 친구들도 각자 자기 티어리스트를 만들 수 있음
- 주 사용 기기: PC

## 2. 무엇을 하려고

- 내 영화 취향을 한눈에 보여주기
- 친구들 취향과 비교하면서 이야기할 거리 만들기

## 3. 화면과 동작

### 티어리스트 만들기
- 등급: A / B / C / D / F (5개)
- 같은 등급 안의 순서는 구분하지 않음
- 영화 옮기기: 끌어다 놓기와 클릭 이동 모두 가능
- 영화 카드: 제목과 개봉 연도가 적힌 색깔 카드
- 이미지: 원하는 사람은 카드에 이미지를 직접 올릴 수 있음
  - 형식: 이미지 파일(JPG, PNG 등)만 올릴 수 있고 그 밖의 파일은 받지 않음
  - 용량: 한 장에 15MB 이하
  - 올린 이미지는 카드 크기에 맞게 줄여서 저장함
  - 카드 메뉴에서 이미지를 바꾸거나 지울 수 있음
- 영화 목록: 기본 8편으로 시작하고 각자 영화를 추가하거나 뺄 수 있음

### 저장
- 이름을 적고 저장하면 결과가 한곳에 자동으로 모임
- 페이지를 닫았다가 다시 열어도 작업이 남아 있음
- 비밀번호 없이 고칠 수 있음

### 비교 화면
- 영화별 표: 영화 한 줄에 사람마다 준 등급을 표시
- 올린 이미지는 모두에게 보임

### 디자인
- 분위기: 어두운 영화관 (검정 배경에 은은한 조명색, 극장에 들어온 느낌)
- 화면 배치, 색상, 글꼴을 신경 써서 디자이너가 만든 느낌을 냄

## 4. 필요한 자료

기본 영화 8편 (아이디어.md 기준)

1. 기생충
2. 인터스텔라
3. 라라랜드
4. 센과 치히로의 행방불명
5. 어벤져스: 엔드게임
6. 범죄도시
7. 타이타닉
8. 토이 스토리

- 실제 영화 포스터는 쓰지 않음 (저작권)
- 이미지는 각 사용자가 직접 올림

## 5. 완성 기준

- [ ] A/B/C/D/F 5개 등급에 영화를 끌어다 놓기와 클릭으로 옮길 수 있다
- [ ] 영화를 추가·삭제하고 이미지를 올릴 수 있다
- [ ] 15MB 이하 이미지는 카드에 보이고 이미지가 아닌 파일이나 15MB를 넘는 이미지는 안내 문구와 함께 거절된다
- [ ] 페이지를 닫았다 열어도 내 작업이 남아 있다
- [ ] 친구가 링크로 들어와 이름을 적고 자기 결과를 저장할 수 있다
- [ ] 2명 이상의 결과가 영화별 표로 함께 나온다
- [ ] PC 브라우저에서 깨지지 않고 보인다
- [ ] 디자이너가 만든 느낌이 나는 화면 (색상·글꼴·여백)

## 참고 사항

- 링크가 있는 사람은 누구나 모든 결과와 이미지를 볼 수 있음
- 비밀번호가 없어서 다른 사람이 같은 이름으로 저장하면 덮어써짐

## 아직 정하지 않은 것

1. 영화 개봉 연도: 카드에 연도를 표시하기로 했는데 아이디어.md에는 제목만 있고 연도가 없음
2. 추가한 영화의 비교 방식: 사람마다 영화 목록이 다를 때 비교표에 모든 영화를 보일지, 겹치는 영화만 보일지
3. 등급을 아직 안 매긴 영화의 자리: 대기 칸을 따로 둘지
4. 저장한 결과 삭제: 고치기는 되게 했지만 자기 결과를 지우는 기능은 정하지 않음
5. 휴대폰 지원 범위: PC를 주 기기로 정했을 뿐 휴대폰에서 어디까지 쓸 수 있어야 할지는 정하지 않음
6. 카드 색상 규칙: 카드 색을 등급별로 할지, 영화마다 고정할지
7. 세부 디자인: 분위기(어두운 영화관)만 정했고 구체적인 색상과 글꼴은 정하지 않음
8. 페이지 이름: 정하지 않음
